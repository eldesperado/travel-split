Git as activity history

Every agent change needed a way back.

Git made progress reversible and inspectable. If the app regressed, the history could be reviewed, reverted, or bisected.

Implementation · tests first
09 / 15
Tests as executable intent

Tests give agents a target they cannot hand-wave.

01
Red
Write a failing test first. The failure proves the desired behavior is not already present.
02
Green
Implement the smallest change that passes. The agent gets concrete feedback.
03
Refactor
Simplify while tests stay green. Preserve behavior and reduce future risk.
For an agent, tests are a reward function. They turn vague intent into executable feedback.

Human loop or metric loop

Every iteration needs a verification signal.

After implementation, the next loop can be manual review or automated measurement. Either way, the agent needs a clear success condition before it changes the product again.

13 / 15
What changed in my engineering workflow?

AI did not remove engineering discipline. It made discipline more valuable.

01
Understand earlier
Move effort into reading specs, finding contradictions, and producing visual artifacts humans can inspect.
02
Plan before code
Use agents to explore options, but choose based on tradeoffs, risks, effort, and maintenance cost.
03
Test as instruction
Turn expected behavior into executable feedback before asking the agent to implement.
04
Verify reality
Use screenshots, browser actions, logs, and builds to prove the running product works.
Discipline becomes the multiplier

Understand → Plan → Implement → Verify → Iterate.

The future is not just faster code. It is faster feedback.
