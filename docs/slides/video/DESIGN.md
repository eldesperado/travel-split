# HyperFrames Visual Identity: Travel Split × Agentic Engineering

## Style Prompt

Swiss Internationalism for an AI engineering field note: precise, grid-driven, high-contrast, technical, and evidence-oriented. Use a warm off-white canvas, near-black typography, and a single International Klein Blue accent. Motion should feel like an engineering system coming online: measured, deterministic, linear reveals, crisp wipes, and loop diagrams assembling from evidence artifacts.

## Colors

- Background / paper: `#fafaf8`
- Foreground / ink: `#0a0a0a`
- Secondary text: `#525252`
- Hairline / grid: `#d4d4d2`
- Accent / IKB: `#002FA7`
- Accent-on text: `#ffffff`

## Typography

- Primary: Inter / Helvetica Neue / Helvetica / system sans
- Mono: JetBrains Mono / IBM Plex Mono / SF Mono
- Headlines: very light weight, large scale, tight leading
- Labels: mono uppercase, letter-spaced

## What NOT to Do

- No gradients.
- No rounded cards.
- No shadows.
- No multi-accent rainbow AI look.
- No generic neon/cyberpunk visual language.
- No decorative emoji.
